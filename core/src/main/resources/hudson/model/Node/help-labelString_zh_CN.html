标签（或标记）用于将多个代理分组到一个逻辑组中。

例如，如果您有多个 Windows 代理，并且有一个必须在 Windows 上运行的任务，那么您可以配置所有 Windows 代理都带有标签 windows，然后将该任务绑定到此标签。
这样可以确保您的任务在其中一个 Windows 代理上运行，但不会在没有此标签的任何代理上运行。

标签不一定代表代理上的操作系统；您也可以使用标签来标注 CPU 架构，或者某个特定工具已安装在代理上。

多个标签必须以空格分隔。例如，windows docker 会为代理分配两个标签：windows 和 docker。

标签可以包含任何非空格字符，但您应避免使用特殊字符，例如 !&|<>() 中的任何一个，因为 Jenkins 的其他功能允许定义标签表达式，在这些表达式中这些字符可能会被使用。
