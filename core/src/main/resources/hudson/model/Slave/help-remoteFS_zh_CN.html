代理需要有一个专用于 Jenkins 的目录。请在代理上指定此目录的路径。最好使用绝对路径，例如 /var/jenkins 或 c:\jenkins 。这应是代理机器本地的路径，无需从控制器可见。

代理不维护重要数据；所有任务配置、构建日志和构件都存储在控制器上，因此使用临时目录作为代理根目录也是可行的。
但是，如果为代理分配一个在机器重启后不会被删除的目录（例如），代理可以缓存工具安装或构建工作区等数据。这可以避免在代理重启后再次开始构建时，不必要的工具下载或源代码重新检出。

如果您使用相对路径，例如 ./jenkins-agent ，则该路径将相对于 启动方式 所提供的工作目录。

  • 对于 Jenkins 控制代理进程启动的启动器（例如 SSH），当前工作目录通常是一致的，例如用户的主目录。
  • 对于 Jenkins 无法控制代理进程启动的启动器（例如从命令行启动的入站代理），当前工作目录可能会在每次代理启动时发生变化，使用相对路径可能会带来问题。
    在入站启动器中使用相对路径时遇到的主要问题是代理机器上陈旧工作区和工具安装的累积，这可能导致磁盘空间问题。
