归档构建构件（例如，分发包 zip 文件或 jar 文件），以便以后下载。归档文件将可从 Jenkins 网页访问。
通常，Jenkins 会保留构建的构件，只要构建日志本身被保留，但如果您不需要旧构件且希望节省磁盘空间，可以这样做。

请注意，Maven 任务类型会自动归档任何生成的 Maven 构件。此处配置的任何构件都将在此基础上额外归档。可以在高级 Maven 选项下禁用自动构件归档。

Pipeline 代码片段生成器 在将所有参数设置为 true 时生成以下示例（某些参数默认即为 true）： 
archiveArtifacts artifacts: '**/*.txt',
                   allowEmptyArchive: true,
                   fingerprint: true,
                   onlyIfSuccessful: true
