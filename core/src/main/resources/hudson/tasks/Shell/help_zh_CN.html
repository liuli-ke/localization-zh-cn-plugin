执行 Shell 脚本（默认使用 sh ，不过可以设置）构建项目，该脚本会在工作区目录中执行。 输入您 Shell 脚本 的内容，如果您的 Shell 脚本没有 #!/bin/sh 这类头部，就会使用系统设置的 Shell 执行。 您也可以使用头部指定使用其他语言的 脚本（例如 #!/bin/perl ）或控制 Shell 使用的选项。

默认会以 "-ex" 选项执行 Shell，所以每个命令都会先打印出来再执行。 如果任何命令结束时返回非零的退出代码，我们就认定构建失败。 再次提醒，加入 #!/bin/... 可以改变这种行为模式。

前人的经验教训指出：千万不要把复杂的 Shell 脚本放在这里。 应该把 Shell 脚本放到 SCM 里，再由 Jenkins 简单地调用它（通过 bash -ex myscript.sh 之类的）。 这样您也可以追溯 Shell 脚本的版本变更。
