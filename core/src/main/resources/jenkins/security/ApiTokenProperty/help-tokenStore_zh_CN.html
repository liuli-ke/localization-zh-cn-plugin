API 令牌提供了一种进行经过身份验证的 CLI 或 REST API 调用的方式。有关更多详细信息，请参阅 我们的 Wiki。
每个令牌关联的用户名即为您的 Jenkins 用户名。

确保 API 令牌安全的一些最佳实践包括：
  • 为每个应用程序使用不同的令牌，这样如果某个应用程序遭到入侵，您可以单独撤销其令牌。
  • 每 6 个月重新生成一次令牌（具体时间取决于您的使用场景）。我们会针对令牌的创建时间显示相应的指示标识。
  • 像保护密码一样保护您的令牌，因为它允许其他人以您的身份访问 Jenkins。
每次 Jenkins 重启时，未使用的旧版 API 令牌的创建日期都会被重置，因此这些日期可能不准确。
