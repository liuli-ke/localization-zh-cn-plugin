此例外所适用的分支名称。名称匹配不区分大小写。 该名称可以是以逗号分隔的名称列表。 名称可以包含 Ant 风格的通配符。在名称前加上 ! 将反转匹配结果。（如果您的实际分支名称以 ! 或 \! 开头，则需要在其前面加上 \ 进行转义。转义仅适用于名称的第一个字符。） 一些示例：
  • production 匹配且仅匹配一个分支
  • sandbox/* 将匹配 sandbox/acme，但不匹配 sandbox/coyote/wiley
  • sandbox/** 将匹配 sandbox/acme 和 sandbox/coyote/wiley
  • production,staging 匹配两个特定的分支
  • production,staging* 匹配 production 分支以及任何以 staging 开头的分支
  • !staging/**,staging/test/** 匹配任何不是 staging 分支的分支，但会匹配 staging/test 分支
  • \!starts-with-invert 匹配名称为 !starts-with-invert 的分支
  • \\!starts-with-escape 匹配名称为 \!starts-with-escape 的分支
  • \escape-only-for-invert 匹配名称为 \escape-only-for-invert 的分支
  • no-internal-!-escape 匹配名称为 no-internal-!-escape 的分支
  • no-internal-\-escape 匹配名称为 no-internal-\-escape 的分支
