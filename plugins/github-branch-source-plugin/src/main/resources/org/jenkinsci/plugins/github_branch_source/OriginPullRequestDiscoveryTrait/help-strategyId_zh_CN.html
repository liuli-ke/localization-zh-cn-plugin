发现 Pull Request 的策略：
将 Pull Request 与当前目标分支修订版合并
每次扫描发现每个 Pull Request 一次，发现的修订版对应与目标分支当前修订版合并后的结果。 请注意，向目标分支推送将触发新的拉取请求构建。
当前 Pull Request 修订版
每次扫描发现每个 Pull Request 一次，发现的修订版对应 Pull Request 头部修订版，不进行合并。
同时检查当前 Pull Request 修订版以及与当前目标分支修订版合并后的结果
每个 Pull Request 被发现两次。第一次发现的修订版对应每次扫描中与目标分支当前修订版合并的结果。 第二次并行发现的修订版对应 Pull Request 头部修订版，不进行合并。
